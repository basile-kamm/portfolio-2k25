Frontend

The Transports lausannois website presents the various services offered by Lausanne's public transport network. The goal was to create a modern and interactive website that could be used to present the different bus and metro lines, as well as timetables and fares.

I worked on this project as a frontend developer, integrating various components and animations of this WordPress website. The site uses Storybook to build and manage reusable components, which allowed me to contribute to a modern and responsive user interface.
